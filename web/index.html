Which board do you have?

Enter bootloader mode

Unplug the Pico, hold the BOOTSEL button, plug it in, then let go. A drive called RPI-RP2 (or RP2350) appears on your computer.

Nuke the old firmware (optional but recommended)

Erases the whole flash — old firmware (Santroller, GP2040, …) and any stored settings — and restores the board to a clean state. The board reboots straight back into bootloader mode when it is done.

⬇ Download flash nuke

Install the YAGCC firmware

Copy the firmware to the bootloader drive. The board restarts by itself and shows up as a guitar controller.

⬇ Download firmware

“Flash directly” (Chrome / Edge) writes the file for you — just pick the bootloader drive when asked.

Button debounce

Filters switch chatter so one press never counts twice. Presses register within ~0.2 ms and releases within ~1 ms; after each change the input is locked for the time below, then re-syncs to where the contact settled. The same approach GP2040-CE uses, plus a tiny glitch filter borrowed from Santroller's hold-off.

Combined strum debounce

Strum up and down share one window, so a bouncing strum bar can't register both.

Lights

Five WS2812 (NeoPixel) LEDs on one data pin, one under each fret. Everything here applies live.

Connect a controller first.

RGB lighting

Enable RGB LEDs

Turn on if you wired a WS2812 chain to the controller.

Data pin

The GPIO connected to the first LED's DIN.
0–255. Five LEDs at full white draw up to ~300 mA from USB; lower values run cooler and are easier on the eyes.

Show the mode on plug-in

Flashes the fret LED that selects the running mode (green = XInput, blue = PS3, yellow = HID by default) for one second.
