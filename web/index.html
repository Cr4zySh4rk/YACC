Enter bootloader mode

Unplug the Pico, hold the BOOTSEL button, plug it in, then let go. A drive called RPI-RP2 (or RP2350) appears on your computer.

Nuke the old firmware (optional but recommended)

Erases the whole flash — old firmware (Santroller, GP2040, …) and any stored settings — and restores the board to a clean state. The board reboots straight back into bootloader mode when it is done.

Button debounce

Filters switch chatter so one press never counts twice. Presses register within ~0.2 ms and releases within ~1 ms; after each change the input is locked for the time below, then re-syncs to where the contact settled. The same approach GP2040-CE uses, plus a tiny glitch filter borrowed from Santroller's hold-off.

Combined strum debounce

Strum up and down share one window, so a bouncing strum bar can't register both.

Supported hardware

Boards, switches, sensors and LEDs you can build a YAGCC guitar with. Wire buttons to any free GPIO — the guided setup works out which pin is which.

Watch out for fake "Pico W" boards. Many cheap boards swap the Raspberry Pi wireless chip for an ESP8285 / ESP8266, which is Wi-Fi only. They work fine over USB with the pico_clone firmware, but can never do Bluetooth. A genuine Pico W has a silver shield marked "Raspberry Pi" over the radio.

Console compatibility

Which mode to use on each console and game. Hold a fret while plugging in to pick the mode (defaults: green XInput, red PS3 Rock Band, yellow HID, blue PS3 Guitar Hero, orange keyboard for Fortnite Festival).

Avoiding console authentication

PS4, PS5 and Xbox One / Series only accept licensed controllers. Two setups don't need any extra hardware:

  • Fortnite Festival: keyboard mode (orange fret). Keyboards are never asked to authenticate.
  • Rock Band 4 on PS4 / PS5: PS3 Rock Band mode (red fret). The game accepts PS3 guitars as legacy instruments.

Everything else on those consoles needs an authentication device on a USB host port, which is planned.
